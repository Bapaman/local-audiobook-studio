# Варианты использования студии аудиокниг

[Диаграмма PNG](diagrams/audiobook-use-cases.png) · [Исходник draw.io](diagrams/audiobook-use-cases.drawio)

## 1. Подготовить голосовой профиль

**Актор.** Владелец проекта.

**Предусловие.** Проект открыт. У владельца есть запись своего голоса длительностью 5–20 минут в WAV (PCM 16 бит, моно, 48 кГц).

**Основной сценарий**

1. Владелец загружает WAV и подтверждает право на использование записи. Студия проверяет файл и открывает его для прослушивания.
2. Владелец выбирает и прослушивает отрезок чистой речи длительностью 10–20 секунд.
3. Владелец вводит точную расшифровку, отмечает «Прослушал и подтверждаю» и нажимает «Подтвердить голосовой фрагмент».
4. Студия сохраняет отрезок и расшифровку в проекте. Подтверждённый образец доступен в разделе «Озвучивание».

**Расширения**

- **1а. Файл не прошёл проверку.** Студия показывает причину. Владелец загружает подходящий WAV.
- **2а. Отрезок короче 10 секунд, длиннее 20 секунд или выходит за границы записи.** Подтверждение недоступно. Владелец исправляет границы и прослушивает отрезок.
- **4а. Владелец хочет дообучить VoxCPM2 на записи.** Он запускает подготовку корпуса, исправляет черновые расшифровки, исключает неподходящие клипы и подтверждает корпус. Затем запускает дообучение. После успешного сохранения адаптер можно выбрать для озвучивания.

**Результат.** В проекте сохранён подтверждённый образец. Если выполнено дообучение, доступно сохранение модели.

## 2. Озвучить текст

**Актор.** Владелец проекта.

**Предусловие.** Проект открыт, голосовой образец подтверждён, локальный движок доступен.

**Основной сценарий**

1. Владелец вводит текст или загружает TXT. Студия сохраняет исходник, нормализует текст и разбивает его на фрагменты.
2. Владелец при необходимости исправляет произношение в тексте и сохраняет правки.
3. В разделе «Озвучивание» владелец выбирает короткий образец или доступное сохранение модели, отмечает нужные фрагменты и нажимает «Озвучить выбранные фрагменты».
4. Студия ставит задание в очередь, показывает число готовых фрагментов и сохраняет WAV по мере обработки.

**Расширения**

- **3а. Выбрана сохранённая модель.** Владелец подтверждает её экспериментальное применение. Перед основным заданием можно проверить голос на одном фрагменте кнопкой «Проба голоса».
- **4а. Владелец нажимает «Пауза» во время синтеза.** Студия завершает текущий фрагмент и приостанавливает задание. По кнопке «Продолжить задание» обработка оставшихся фрагментов возобновляется.
- **4б. Синтез завершился ошибкой.** Студия показывает причину. После её устранения владелец запускает новое задание для недостающих фрагментов.

**Результат.** Для выбранных фрагментов сохранено аудио. В истории видны состояние задания и его результаты.

## 3. Прослушать и экспортировать аудиокнигу

**Актор.** Владелец проекта.

**Предусловие.** В проекте есть выбранный текст и хотя бы один озвученный фрагмент.

**Основной сценарий**

1. Владелец открывает результаты озвучивания выбранного текста.
2. Владелец прослушивает аудио в списке фрагментов или в истории заданий.
3. Когда задание завершилось и для всех фрагментов есть аудио, владелец нажимает кнопку скачивания WAV для выбранного текста.
4. Студия собирает фрагменты в порядке текста. Браузер скачивает один WAV.

**Расширения**

- **2а. Найдена ошибка произношения.** Владелец исправляет произносимый текст, сохраняет правку и повторно озвучивает выбранный фрагмент. После успешного синтеза новый результат используется при сборке WAV.
- **3а. Часть фрагментов без аудио.** Скачивание всей книги недоступно. Студия предлагает сначала озвучить все фрагменты.
- **3б. В тексте больше 256 фрагментов.** Единый WAV недоступен. Владелец скачивает доступные фрагменты из истории заданий.

**Результат.** Аудиокнига скачана одним WAV в порядке фрагментов выбранного текста.
