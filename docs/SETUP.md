# Запуск на другом компьютере

Студия рассчитана на Windows 10/11 x64. Интерфейс работает в браузере, сервер и вычисления — на этом же компьютере.

## Сначала открыть интерфейс

Установить Git, PowerShell, .NET SDK **10.0.401** и Node.js **24**. Версия SDK закреплена в `global.json`, версии пакетов — в lock-файлах.

```powershell
git clone https://github.com/Bapaman/local-audiobook-studio.git
cd local-audiobook-studio
.\scripts\app\Start-LocalStudio.ps1 -Configuration Release
```

Первая сборка восстанавливает NuGet- и npm-пакеты. Для этого нужен интернет. Скрипт откроет страницу студии в обычном браузере. Порт выбирается при каждом запуске, поэтому постоянная ссылка на localhost не используется.

Без речевых моделей интерфейс открывается, но озвучивание и обучение недоступны. Это позволяет отдельно проверить сборку и работу с проектами.

Данные проектов находятся в `%LOCALAPPDATA%\LocalAudiobookStudio`. Для завершения сервера предусмотрена кнопка «Выйти из приложения»; закрытие вкладки само по себе его не останавливает.

## Подключить речевой движок

Для вычислений нужны дополнительные внешние ресурсы: Python 3.11, совместимые зависимости, закреплённые исходники и веса моделей. Они не входят в Git-репозиторий. Кнопки интерфейса не устанавливают эти ресурсы автоматически.

Версии и контрольные суммы перечислены в `eng/locks/`. В `scripts/voxcpm-training/New-LocalRuntime.ps1` находится подготовка дескриптора из уже существующего окружения. Этот скрипт проверяет файлы, а не устанавливает полноценное окружение и не создаёт frozen-cache с нуля. Текущий путь подготовки требует отдельной настройки на новом компьютере.

Готовые локальные дескрипторы можно передать запуску:

```powershell
.\scripts\app\Start-LocalStudio.ps1 `
  -Configuration Release `
  -TtsCorpusRuntimeConfig 'C:\Models\Studio\corpus-runtime.json' `
  -VoxCpmTrainingRuntimeConfig 'C:\Models\Studio\voxcpm-runtime.json'
```

Пути здесь приведены как пример. Дескрипторы создаются для конкретных файлов и установленного окружения; переносить чужой дескриптор без повторной проверки нельзя.

CPU-путь VoxCPM2 допускает запуск при 16 ГиБ свободной физической памяти. Для вычислительного процесса установлены ограничения: два логических процессора, 13 ГиБ памяти и 300 секунд на нативное окно. Подготовка окружения тоже занимает время. Компьютеру с 16 ГиБ общей памяти этого обычно недостаточно.

## Первый проект

1. Создать проект и загрузить WAV со своей записью.
2. Прослушать и подтвердить голосовой образец с точным текстом.
3. Добавить небольшой текст, сохранить произносимую версию.
4. Выбрать доступный режим и начать с короткой пробы.
5. Для дообучения сначала подготовить и подтвердить корпус речи.

Сходство с исходным голосом и качество интонации пока дорабатываются. Студия остаётся учебным прототипом.
