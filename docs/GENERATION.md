# Как подбирать голос в студии

Эта инструкция относится к сохранённым моделям VoxCPM2. Движок и модель
должны быть настроены на компьютере заранее.

## Первая проба

1. Откройте проект с записью, подтверждённым корпусом и сохранением обучения.
2. Добавьте небольшой текст и сохраните правки произносимой версии.
3. В разделе «Озвучивание» выберите голос **VoxCPM2** и нужный шаг обучения.
4. Подтвердите экспериментальное применение модели. Пока для запуска также
   нужен подтверждённый образец на 10–20 секунд в подготовке проекта.
5. Оставьте настройки по умолчанию и нажмите «Проба голоса».
6. Прослушайте результат в истории. Там же можно скачать WAV.

Перед запуском нужно не менее 16 ГиБ свободной оперативной памяти.
Подготовка движка может занимать время: студия проверяет локальные файлы.
Память проверяется повторно после подготовки. Если её стало меньше 16 ГиБ,
синтез не начнётся: освободите память и создайте новую пробу. Для запаса
полезно закрыть тяжёлые программы ещё до открытия студии.
Закрытие вкладки не останавливает сервер. Для выхода используйте
«Выйти из приложения».

## Что меняют настройки

| Настройка | Как ей пользоваться |
| --- | --- |
| Seed — вариация | Начните с 42. «Новая вариация» выбирает другое число. На одном тексте результат может звучать иначе. |
| Шаги синтеза | По умолчанию 10, диапазон 4–20. Больше шагов требует больше вычислений; улучшение не гарантируется. Это не продолжение обучения. |
| CFG | По умолчанию 2, диапазон 1–3. Меняет силу условия при синтезе; результат нужно сравнивать на слух. |
| Темп экспортируемого аудио | 100% оставляет исходный звук. 90% делает запись медленнее; 110% — быстрее. Меняется сам скачиваемый WAV. |
| Опорный клип | Помогает задать голос и манеру речи по фрагменту той же подтверждённой записи, на которой обучалась модель. |

Для темпа, отличного от 100%, применяется дополнительная обработка
с приблизительным сохранением высоты голоса. Она может давать артефакты.
Отдельной настройки высоты или глубины голоса пока нет.

Автоматический выбор берёт подходящий клип, ближайший к 12 секундам.
Можно выбрать другой клип и сначала послушать настоящий голос в нём.
Отключение опорного клипа сохраняет выбранную обученную модель.

## Как сравнивать результаты

Используйте один и тот же текст. Меняйте один параметр за раз — иначе
сложно понять, что помогло. Для слишком быстрой речи начните с темпа 90%,
оставив остальные значения прежними. Это проверка темпа, а не способ
исправить сходство голоса.

Каждое задание сохраняет свои настройки, модель, шаг обучения и выбранный
опорный клип. Они видны под результатом. Кнопка «Использовать эти настройки»
возвращает их в форму; для нового запуска снова требуется подтверждение.
Во время выполнения настройки текущего задания не меняются.

Пауза применяется после текущего фрагмента. Отмена завершает задание через
штатную остановку. Чтобы озвучить новый текст, сохраните его в проекте,
выберите нужные фрагменты и нажмите «Озвучить выбранные фрагменты».

История в интерфейсе ограничена последними заданиями; результаты остаются
в проекте. Книгу можно скачать одним WAV, когда озвучены все её фрагменты.
Для одного такого файла поддерживается до 256 фрагментов.

Сохранение модели и применение её к синтезу ещё не означают, что голос
уже достаточно похож на исходный. Сходство, ударения и интонацию нужно
проверять отдельно, прежде чем запускать длинную книгу.
